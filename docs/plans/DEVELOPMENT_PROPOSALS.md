## 0. واقع النظام المؤكد بالفحص (تصحيح أخطاء النسخة السابقة)

هذه الحقائق تحل محل أي وصف قديم/تخميني:

| البند | الحقيقة المؤكدة في الكود |
|---|---|
| حجم `AppContext.tsx` | **4653 سطراً** (ليس 1800) — God Object حقيقي والأخطر في الصيانة |
| قاعدة البيانات | **PostgreSQL أساسي** عبر Prisma (ملف `.env` فيه `DATABASE_URL`، ومجلد `prisma/migrations` موجود: `init` + `cdc_change_log`). **SQLite مجرد fallback** محلي عند غياب `DATABASE_URL`. Migrations مدارة فعلاً بـ Prisma |
| النسخ الاحتياطي | نظام كامل موجود في `server/routes/backup.mjs`: نسخ مجدولة + استبقاء (retention) + **تحقق من سلامة النسخة** بعد كل نسخ + **نقطة استعادة تلقائية قبل العمليات التدميرية** + استعادة يدوية. ما ينقص فعلاً: **التشفير** فقط |
| الاختبارات | 5 ملفات وحدة: `merge, cdc, auth-utils, totp, repository` (في `server/test`). **لا اختبارات واجهة Frontend** و**لا E2E** |
| تقسيم الكود | **منجز بالفعل** — `App.tsx` يستخدم `React.lazy` + `Suspense` لكل الشاشات (البيان "Code splitting already done" صحيح) |
| الحزمة الكبيرة | القرص `index-*.js` (~1.9MB) سببه **recharts** (قاعدة رسوم ضخمة)، وليس الشاشات — lazy لن يحلها، بل تؤجل تحميل recharts |
| Logging | `console.log` + ملف `savelog.txt` + جدول `audit_log`. **لا structured logging ولا metrics** |
| Error Boundaries | غير مستخدمة في React إطلاقاً |
| Pagination/Virtualization | لا endpoint بتقسيم صفحات ولا مكتبة virtual — شريطة النمو الكبير فقط |
| توثيق API | لا OpenAPI/Swagger |
| ربطه الخارجي | Cloudflare tunnel: `erp.restocost.shop` → منفذ 3001 المحلي |

### اعتقاد خاطئ حذفناه
- نسخة الوثيقة السابقة قالت "SQLite مضمنة + Prisma اختياري" — **الحقيقة معكوسة تماماً**.
- "Backup = JSON فقط" دون نظام نسخ — **العكس، يوجد نظام نسخ متكامل**.
- TanStack Query كبديل لـ AppContext — **خطر**: يُهمل الـ merge بالمعرّف + شواهد الحذف + دفعات المزامنة؛ لا ننفذه.

```
المرحلة 1: القاعدة (مكاسب سريعة آمنة)
```

**القاعدة الحاكمة:** لا خطوة تغيّر طريقة عمل المزامنة الحالية (POST /api/collections + merge). أي تغيير يحافظ على سلوك المستخدم الحالي.

## 2. المرحلة 1 — القاعدة الآمنة (أيام 1–3)

إضافات معزولة لا تلمس المنطق، كلٌّ يعمل لوحده.

### 2.1 Error Boundaries (أولاً — فائده فورية)
- ملف جديد: `src/components/ui/ErrorBoundary.tsx` (class component + fallback مرئي + زر إعادة تحميل).
- الإدماج: في `App.tsx` حصر نطاقات `renderView()` + داخل أهم 3 شاشات (Inventory, Reports, MobileCount).
- **الهدف:** إن سقط استثناء في شاشة لم تعد تجمّد التطبيق كاملاً.

### 2.2 `/health` + `/ready` + `X-Request-ID`
- `server/index.js`: إضافة `app.get('/health')` و`app.get('/ready')` (يفحص DB).
- Middleware يعيّن `X-Request-ID` لكل طلب ويردّ بشكل فوري في الاستجابة.
- **الهدف:** تشخيص سريع لمشاكل مثل "HTTP 400" الذي رأيناه، مع سجل قابل للربط.

### 2.3 Structured logging (بديل سجل المشكلات)
- إدخال `server/logger.mjs` يعرض: `ts | level | reqId | action | key | status | ms | ua`.
- توجيه نقاط الإبلاغ الحالية (`savelog.txt`) إليه مع استبقاء السطر الحالي للتوافق.
- **الهدف:** قراءة أخطاء بعيد اللقطة من سطر واحد مفكك.

## 4. المرحلة 3 — تفكيك AppContext (أسابيع 2–4)

**بدون TanStack Query.** نستبدل الشرائح تدريجياً بـ hooks محلية داخل نفس `AppContext` (نوفر إعادة كتابة جذرية):

| الشريحة | الفعل |
|---|---|
| المزامنة والحفظ المعلّق (`syncNow`, `pendingSaves`, `flushSaves`) | استخراج `useSyncEngine(internal setters)` في `src/context/syncEngine.ts` — يقيّد أعقد منطق في مكان واحد قابل للاختبار |
| البيانات (بكس الأكواد الثابتة per collection) | لا يتغير — `applyData` يبقى — فقط نقل كتلة callback للمزامنة |
| الجلسة/المستخدم | فصل خفيف `useAuthSlice` |
| Toast/النسخة/الثيم | `UIContext` مستقل صغير |

**معيار إتمام كل خطوة:** `flushSaves` العلوم والمزامنة الحية تعملان، و`npm run build` سليم، واختبار يدوي سريع للجرد.

## 5. المرحلة 4 — الأداء والتوثيق (أسبوع 5)

### 5.1 تحسين الحمل
- تحسين recharts: `import()` ديناميكي للرسوم داخل الشاشات (تأجيلها للطلب) — لا يلمس البنية.
- إن لزم بعدها: `createManualChunks` لفصل `react`/`recharts` في chunk منفصل.

### 5.2 Pagination (فقط عند الحاجة)
- أضف `GET /api/collections/:key/paginated` (نقط بسيطة بالـ cursor) كشف عند نمو قائمة واحدة > 1000 سجل (مثل Recipes). **لا تُجبر الآن**.

### 5.3 توثيق API (اختياري، منخفض الأولوية)
- نقطة `GET /api/openapi.json` تولّد وصفاً يدوياً لجزء استياط — لا مكتبات إضافية.
