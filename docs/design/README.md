## القرارات المُتخذة

**الجداول**: بنمط Oracle `<table>` حقيقي لا شبكات `div` — المحاذاة ثابتة.
**أعمدة الإجراءات**: نصّ بارز (طباعة · تفاصيل) + أيقونات للمKellywise (نسخ · تعديل).
**فتح السجل**: بزر «تفاصيل» صريح — الصف **لا** يفتح بالنقر (سلوك Oracle، يمنع الفتح بالخطأ على الجوال).
**الألوان**: slate كقاعدة + indigo للعنصر النشط + دلالات حالة (emerald/amber/rose).
**الأرقام**: `tabular-nums` + `dir=ltr` + محاذاة يسار.
**التقارير**: بطاقات لا جداول (26 عنصراً مت异نوع)، والجدول للقوائم المتشابهة.
