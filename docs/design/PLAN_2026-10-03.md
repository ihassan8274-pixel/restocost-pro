## المرحلة 1 — تطوير الشاشات (أولوية مطلقة)

### 1.1 بناء نظام التصميم `src/components/ui/erp/`

المصدر: `docs/design/` (3 نماذج معتمدة).

| الملف | المكوّن | القاعدة |
|---|---|---|
| `Button.tsx` | `ErpButton` | 3 أنماط: primary / secondary / disabled |
| `Field.tsx` | `ErpField` | label + input موحّد |
| `DataTable.tsx` | `ErpTable` | جدول حقيقي، ترقيم، فرز |
| `StatusChip.tsx` | `ErpChip` | 5 حالات لونية |
| `KpiBar.tsx` | `ErpKpi` | بطاقات إحصاء |
| `QueryBar.tsx` | `ErpQueryBar` | صندوق المعاملات (Oracle QBE) |
| `ReportLayout.tsx` | `ErpPage` | ترويسة + محتوى |
| `ActionCell.tsx` | `ErpActions` | طباعة · تفاصيل (نصّ) + نسخ · تعديل (أيقونة) |

**القواعد المعتمدة**:
- الجداول `<table>` حقيقية — لا شبكات `div`
- أعمدة الإجراءات: نصّ بارز (طباعة · تفاصيل) + أيقونات للثانوي
- فتح السجل بزر «تفاصيل» — **الصف لا يفتح بالنقر**
- الأرقام `tabular-nums` + `dir=ltr` + محاذاة يسار
- الألوان: slate + indigo + دلالات (emerald / amber / rose)

**مدة: يومان**

| المجموعة | العدد | المدة |
|---|---|---|
| تقارير | 49 | 10 أيام |

## المرحلة 3 — دعم متعدد الشركات (اختياري)

يُنفَّذ **بعد** استقرار الرفع — فقط إذا احتجت توسعاً حقيقياً.

| الخيار | المدة | متى |
|---|---|---|
| **شاشة تحكم خارجية** (كل شركة dir منفصلة) | يوم | إذا جهاز واحد |
| **عزل بيانات RLS** (عمود company_id) | 4 أيام | إذا جهازان متوازيان |
| **رابط لكل شركة** `/c/<company>` | يوم | إذا روابط مستقلة |

**ملاحظة**: هذه المرحلة **ليست ضرورية** للنشر الأول.
